# 📖 Glossário Git para Estudantes

> Um guia rápido, prático e interativo com os conceitos, comandos e fluxos essenciais do Git para estudantes e iniciantes no desenvolvimento de software.

---

## 💻 Sobre o Projeto

Este projeto consiste em uma página web interativa criada para facilitar a consulta rápida de comandos e conceitos fundamentais do Git. A aplicação conta com uma busca em tempo real, tópicos explicativos e um guia prático para resolução de conflitos de merge.

Este repositório também foi utilizado como **ambiente de treino para fluxo de trabalho colaborativo em equipe**, simulando o modelo **Git Flow** com criação de *branches*, revisão de *Pull Requests*, tratamento de *conflitos* e marcadores de versão (*tags*).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização responsiva, variáveis de tema e layout em Grid.
* **JavaScript (ES6+):** Renderização dinâmica dos cards e lógica do filtro de busca em tempo real.
* **Git & GitHub:** Controle de versão e gestão de *backlog* via Issues e PRs.

## 🌿 Estrutura de Branches (Git Flow)

O desenvolvimento seguiu uma adaptação do modelo **Git Flow**:

* **`main`:** Branch de produção, contendo apenas código estável e releases oficiais.
* **`develop`:** Branch de integração onde todas as novas funcionalidades são unificadas e testadas.
* **`feat/*`:** Branches temporárias para o desenvolvimento de cada *issue* ou funcionalidade individual.
* **`release/*`:** Branch de preparação para o lançamento da versão estável.
