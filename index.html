Glossário Git

Conceitos Fundamentais

Repository (Repositório)

Espaço de armazenamento onde o Git guarda todo o histórico de alterações do seu projeto (pasta .git).

Commit

Um "instantâneo" (snapshot) do seu código em um determinado momento. Cada commit possui um ID único (hash).

Branch (Ramificação)

Uma linha de desenvolvimento independente. Permite criar funcionalidades sem afetar o código principal (main).

Working Tree / Staging Area / Local Repo

Os 3 estados locais do Git: o diretório de trabalho atual, a área de preparação (index) e o repositório local salvo.

Lidadando com Conflitos

O que fazer em caso de Merge Conflict?

  1. Abra os arquivos com conflito (marcados com <<<<<<< e >>>>>>>).
  2. Edite o código mantendo apenas a versão final desejada e remova as marcações do Git.
  3. Adicione o arquivo corrigido ao staging: git add nome-do-arquivo.
  4. Finalize a integração executando apenas: git commit.

Comandos Mais Usados

git init

Inicializa um novo repositório Git na pasta atual do projeto.

git status

Exibe o estado dos arquivos: modificados, não rastreados (untracked) ou prontos para o commit.

git add

Adiciona arquivos modificados à área de preparação (Staging Area). Use git add . para adicionar tudo.

git commit -m "mensagem"

Grava as alterações registradas no staging area com uma mensagem explicativa do que foi feito.

git branch

Lista as branches existentes. Use git branch nome para criar uma nova ou git branch -d nome para deletar.

git checkout / git switch

Alterna entre branches. Use git checkout -b nome para criar e mudar para a branch nova ao mesmo tempo.

git merge

Junta as alterações de outra branch na branch onde você está posicionado atualmente.

git clone [url]

Baixa a cópia de um repositório remoto existente no GitHub para a sua máquina local.

git push

Envia os commits realizados localmente para o repositório remoto (ex: GitHub).

git pull

Baixa e integra automaticamente as alterações do repositório remoto na sua branch atual (Fetch + Merge).

git log --oneline

Exibe o histórico de commits do projeto de forma simplificada e resumida em uma linha por commit.

git stash

Guarda temporariamente as alterações não salvas (rascunho) em uma "gaveta" para limpar o ambiente de trabalho.

git tag -a [nome] -m ""

Cria uma etiqueta anotada em um commit específico para marcar versões oficiais de lançamento (ex: v1.0).

git reset

Desfaz commits ou remove arquivos do Staging Area, podendo alterar o histórico de desenvolvimento.
